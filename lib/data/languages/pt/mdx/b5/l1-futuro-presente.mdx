<Rule title="Futuro do presente: la base de los irregulares es el infinitivo">En portugués, el futuro simple se forma añadiendo las terminaciones '-ei, -ás, -á, -emos, -ão' directamente al infinitivo del verbo: falar → falarei, comer → comerei, partir → partirei. Este es el mismo procedimiento que en español, pero las terminaciones son diferentes. Los verbos irregulares no cambian el infinitivo como base; lo que varia es la vocal temática. Los más comunes son: 'ser' → serei, 'estar' → estarei, 'ter' → terei, 'ir' → irei, 'fazer' → farei, 'dizer' → direi, 'vir' → virei, 'ver' → verei, 'poder' → poderei, 'querer' → quererei, 'saber' → saberei, 'dar' → darei, 'trazer' → trarei, 'pôr' → porei. Observa que mantienen la raíz irregular del presente y simplemente reciben las terminaciones regulares del futuro. La principal trampa para hispanohablantes es que en español decimos 'seré, estaré, tendré' (con cambio total), mientras que en portugués es 'serei, estarei, terei' (infinitivo + terminación). No intentes adaptar el verbo español; parte siempre del infinitivo portugués.</Rule>
