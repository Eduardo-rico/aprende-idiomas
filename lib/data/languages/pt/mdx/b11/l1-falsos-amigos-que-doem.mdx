<Rule title="Falsos amigos: cuando la palabra existe y por eso duele más">Los falsos amigos peligrosos para un hispanohablante C1 no son los inventados — son los que EXISTEN en portugués con otro sentido. 'Esquisito' es raro, no exquisito; 'polvo' es el pulpo, no el polvo ('pó'); 'oficina' es el taller, no el despacho ('escritório'); 'pelo' es pelaje, no cabello ('cabelo'); 'esperto' es listo, no experto ('perito'); 'constipado' es resfriado (tranquilidad); 'apelido' en Portugal es el apellido (amigo VERDADERO aquí — el sentido 'apodo' es brasileño); y 'regalo' sobrevive en la literatura como deleite o manguito, nunca como presente ('presente', 'prenda'). La regla de oro C1: cuando una palabra portuguesa se parece demasiado a la tuya y el contexto rechina — párate. El diccionario del lector (toca la palabra) está para eso.</Rule>

### Vocabulário

- **esquisito** — raro, extraño (NUNCA exquisito: eso es 'delicioso')
- **o pó / o polvo** — el polvo / el pulpo
- **a oficina / o escritório** — el taller / la oficina
- **o cabelo / o pelo** — el cabello / el pelaje o vello
- **esperto / perito** — listo, despierto / experto
- **constipado** — resfriado
- **a sandes** — el bocadillo (BR: sanduíche)
- **o presente, a prenda** — el regalo
