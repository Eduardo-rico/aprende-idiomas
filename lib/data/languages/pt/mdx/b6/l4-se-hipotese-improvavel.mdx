<Rule title="Se + Conjuntivo: hipótesis improbables e irreales">En portugués, cuando expresamos condiciones irreales o improbables en el presente o el pasado, usamos 'Se' seguido del conjuntivo (subjuntivo). Para el presente/futuro irreal se emplea el 'imperfeito do conjuntivo' (se eu soubesse, se eu tivesse), y para el pasado irreal se usa el 'mais-que-perfeito do conjuntivo' (se eu tivesse sabido, se eu tivesse ido). La consecuencia se expresa con el condicional compuesto ('teria feito'). Este patrón es diferente del español, donde solemos usar el condicional simple en ambos casos.</Rule>

### Vocabulário

- **talvez** — tal vez
- **ardia** — ardía, quemaba
- **prometeu** — prometió
- **suspiar** — suspirar
- **rumo** — rumo, dirección
