<Rule title="El gerundio portugués: -ando, -endo, -indo">El gerundio portugués se forma con las terminaciones -ando (verbos -ar), -endo (verbos -er/-ir) e -indo (verbos -ir con cambios). Ojo: no equivale al gerundio español. En portugués, el gerundio se usa principalmente con verbos auxiliares para formar el pasado progresivo. Los auxiliares principales son 'estar', 'andar', 'ir' y 'vir', cada uno con un matiz: 'estar' indica acción en curso, 'andar' sugiere repetición o hábito, 'ir' marca un proceso gradual y 'vir' una evolución hacia un estado.</Rule>

### Vocabulário

- **acordar** — despertar / levantarse
- **encontrar** — encontrar(se), maar ook: encontrar alguien = encontrarse con alguien (quedar)

<Example index={1} audioRef={1} pt="Andamos estudando muito este mês." es="Andamos estudiando mucho este mes." />

<Example index={2} audioRef={2} pt="O menino vai ficando mais calmo." es="El niño va poniéndose más tranquilo." />

<Tip>Para recordar: si en español dices 'está hablando', en portugués es 'está falando'. El gerundio portugués con auxiliares funciona como el 'estar + gerundio' español, pero NO uses la estructura '-ando/-iendo' sola como en español ('hablando' no existe solo en portugués).</Tip>
